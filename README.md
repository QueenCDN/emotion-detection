# Emotion Detection Project

An AI-based web application that detects emotions in text using the IBM Watson NLP library.

## Features
- Detects five emotions: anger, disgust, fear, joy, sadness
- Identifies the dominant emotion
- Web deployment with Flask
- Unit tested and error-handled

## Emotions Detected
anger, disgust, fear, joy, sadness

## Usage
Run the Flask server:
\`\`\`bash
python server.py
\`\`\`
Then open the app and enter text to analyze.
